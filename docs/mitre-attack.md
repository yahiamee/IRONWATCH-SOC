# MITRE ATT&CK Mapping

This project demonstrates how AI can assist analysts by suggesting possible MITRE ATT&CK techniques based on the information provided in a security alert.

## Purpose

The workflow does not claim that a specific technique has been confirmed.

Instead, it provides informed suggestions that should be validated by a human analyst.

## Example

Alert:

- Suspicious PowerShell Execution

Possible Mapping:

- T1059 – Command and Scripting Interpreter
- T1059.001 – PowerShell

These mappings are clearly presented as analytical assessments rather than confirmed findings.

## Important Note

MITRE ATT&CK suggestions should always be validated against additional evidence during an investigation.
