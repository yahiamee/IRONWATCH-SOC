# Contributing

Thank you for your interest in contributing to this project.

## Reporting Issues

If you discover a bug or have a suggestion, please open an issue describing:

- The problem
- Expected behaviour
- Steps to reproduce
- Screenshots if applicable

---

## Pull Requests

Pull requests are welcome.

Please ensure that:

- Documentation is updated.
- Code is well documented.
- Changes remain consistent with the project's objectives.
- Commit messages are meaningful.

---

## Project Goals

This repository focuses on:

- AI Automation
- Cybersecurity
- Prompt Engineering
- Workflow Automation
- Security Operations Center (SOC) processes

Thank you for helping improve the project.
